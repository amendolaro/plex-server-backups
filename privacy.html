Plex Server Backups

Privacy policy

Effective September 19, 2026.

Purpose and data use

Plex Server Backups is a personal utility operated by its owner to back up and restore server configuration data. It uses Google Drive file contents, metadata and storage-quota information to upload, verify, restore and maintain encrypted backups.

Google authorization

The utility requests Google Drive access to work with the owner's existing backup repository. Although this permission allows access to other Drive files, the configured backup jobs target the designated backup folder. OAuth credentials are stored on the owner's server with restricted file permissions.

Storage and sharing

Backup data is encrypted with restic before upload to Google Drive. Backup data is not sold, used for advertising or used to train artificial intelligence models. Google stores the uploaded data under the owner's Google account. This public website contains no backup files or authentication credentials.

Retention and control

The intended retention is the ten most recent successful snapshots. Shared backup data may remain while referenced by a retained snapshot. The owner can stop backup jobs, remove backup files or revoke application access through Google Account settings. Revoking access does not delete existing backups.

Website hosting

These informational pages use no custom analytics, tracking scripts or forms. GitHub Pages hosts the website and may process ordinary access logs under GitHub's privacy statement.

Questions

This application has no public users or registration. The owner manages its Google authorization, backup retention and deletion directly.
