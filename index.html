Plex Server Backups

A personal backup utility that uses rclone and restic to store encrypted server configuration backups in the owner's Google Drive.

This application is for the owner's personal use. It is not a public backup service and does not offer registration or access to backups through this website.

Google Drive authorization allows the utility to upload, check, restore and manage backup files. Backup contents and authentication credentials are not published on this website.
